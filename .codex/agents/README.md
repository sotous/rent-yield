# Agent Roles

These files define specialized agent roles for work inside `rent-yield`.

They are not the primary repository policy.

The canonical repository-wide rules live in:

- [AGENTS.md](../../AGENTS.md)
- [CLAUDE.md](../../CLAUDE.md)

Use these role files as focused overlays on top of the global workflow, not as replacements for it.

## Available Roles

- [frontend-agent.md](frontend-agent.md)
- [backend-agent.md](backend-agent.md)

## Usage Principle

Choose the role that best matches the task, but keep the shared repo workflow intact:

`plan -> build -> review -> iterate -> document`
